# 真实多卡公开版设计

日期：2026-08-09

## 目标

把当前只有一张中性演示卡的公开仓库升级为 Zomo Design 的真实十卡展览效果，同时维持代码可开源、真实视觉资产不可自由复用、仓库不包含本机或部署隐私信息。

## 方案比较

1. **完整十卡混合授权（采用）**：公开完整交互代码和十张真实卡的四类贴图，代码使用 MIT，真实卡片、品牌和视频另行保留全部权利。优点是 GitHub 运行效果与真实展览一致；代价是素材更容易被整包下载。
2. **三张精选卡混合授权**：下载量和素材暴露更少，但不能完整展示多卡轮播，也不能解决当前演示效果偏弱的问题。
3. **只开源代码、README 放视频**：素材风险最低，但访问者无法直接运行真实效果，与用户本次目标不符。

用户已确认采用方案 1，并接受公开网页素材本身可被下载这一事实。

## 公开内容

### 代码与配置

- 保留当前公开仓库已经审计过的 `index.html`、便携启动脚本、递归校验脚本和 GitHub Actions。
- 使用真实展览标题、Zomo Design 品牌文字、卡片顺序、粒子和壁烛配置。
- 保留当前公开版已经补齐的键盘操作、对话框语义、焦点管理、减少动态效果和 WebGL 静态降级。

### 真实卡片

公开以下十张卡，每张包含 `card-config.json`、原图、法线图、高度图和粗糙度图：

- `cat-portrait`
- `gilded-muse`
- `november-forest`
- `red-poppies`
- `hibiscus`
- `narcissus`
- `sword-book`

### 品牌和动效素材

- 使用真实品牌标记。
- 使用自定义烛光光标。
- 使用页面实际引用的优化壁烛循环视频和封面图。
- 不加入未被页面使用的原始大视频。

## 明确排除

- Finder 元数据文件。
- 本地部署关联目录 `.vercel`。
- 含个人目录或特定工具安装路径的旧启动脚本。
- 单卡调试页面和单卡预览脚本。
- 页面未引用的素材和中间文件。
- 任何令牌、账号凭据、项目 ID、组织 ID 或绝对本机路径。

## 授权边界

- HTML、JavaScript、CSS、JSON 配置结构、校验脚本和启动脚本继续使用 MIT License。
- 十张真实卡的原图、法线图、高度图、粗糙度图，以及品牌标记、光标、壁烛视频和封面图不属于 MIT。
- `ASSETS.md` 将明确写明这些视觉资产版权归 Zomo Design，默认仅供查看和运行本项目，未经书面许可不得复制、再发布、改作、训练素材包或商业使用。
- README 的许可证段落必须明确区分“开源代码”和“保留权利的视觉资产”，避免整仓 MIT 的误解。

这是一种混合授权仓库：软件代码开源，视觉内容不是开放素材库。

## 页面结构与数据流

1. 页面加载 `gallery-config.json` 获取展览文案、卡片顺序和全局交互参数。
2. 对顺序中的每张卡加载对应 `card-config.json`。
3. 首页只使用原图构建多卡轮播；点击卡片时再加载四张贴图并创建 WebGL2 渲染器。
4. WebGL 不可用、贴图缺失或上下文丢失时，保留静态原图并显示说明，不阻断其他卡片。
5. 所有路径使用仓库内相对路径，不依赖特定电脑、账号或外部服务。

## 校验与错误处理

- 校验脚本递归扫描所有公开文本文件，拒绝绝对用户目录、部署关联目录、凭据形式和未审查外链。
- 校验 `gallery-config.json` 中十张卡均存在，并确认每张卡的四项贴图文件齐全。
- 校验真实品牌、光标、壁烛视频和封面图存在，但不把二进制视觉素材误判为文本。
- 浏览器验收覆盖：首页出现多张不同尺寸卡片、拖动/滚轮/键盘切换、打开详情、左右换卡、鼠标追光、卡片倾斜、模糊蒙层、移动端、减少动态效果和静态降级。
- 自动化检查通过后才允许合并到 `main`。

## 发布方式

- 在独立分支完成迁移和清洗。
- 通过 Draft Pull Request 展示完整差异和测试结果。
- 不覆盖私人最终版目录；它继续作为原始工作副本。
- 合并后公开仓库将展示真实十卡效果，当前单张几何演示素材将从默认展览中移除。
